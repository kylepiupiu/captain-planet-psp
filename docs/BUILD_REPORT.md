# 构建与验证报告

日期：2026-10-03；版本：0.1；目标：PSP native homebrew。

## 通过

- PSPSDK：生成 MIPS PRX 和 EBOOT.PBP。仅有生成头文件未使用静态字符串数组的编译警告。
- 113 条任务：季数为 26/26/13/22/13/13；十种任务类型均有覆盖。
- 逐关以真实移动输入寻路，检查目标、出口可达和目标交互、元素匹配、通关记录。护送同伴通过实际 BFS 跟随到出口，测试未传送同伴。
- 路径测试隔离敌人伤害并跳过首领战，不等于 113 关完整实战通关。独立战斗测试使用真实投射物击败受控敌人。
- 能量召唤、持续时间结束、暂停冻结模拟通过。
- 存档有效性、校验、临时写入验证、备份恢复、非法关卡索引和写入失败报告通过。
- 3200 步随机输入、1600 次渲染，AddressSanitizer / UndefinedBehaviorSanitizer 未报告问题。
- 实际 EBOOT 在 PPSSPP Headless / null 图形后端执行；通过 debugger 按键接口从标题进入简报、游戏，移动，再暂停。从 PSP 显存读取 480×272 图像，确认并非仅主机端渲染。
- 原生启动日志包含 P01 至 P08，ALL_ASSETS_READY、AUDIO_READY、LOOP_RUNNING。

## 尚未验证

PSP 真机启动、持续帧率、功耗、电池与休眠恢复；音频主观听感；全部关卡战斗节奏、无伤/低血量平衡；长时间重复游玩与多种固件兼容。

## 内容边界

当前可玩，但属于垂直切片向全剧目录扩展的原型。113 关共用任务框架，地图为程序生成；剧情简报来自公开简介，没有逐集观看原片。人物二维行走图集只有基础方向与少量步行动画，尚未达到用户要求的一比一；未制作完整对话、过场、原作反派专属造型与攻击动画。

后续优先顺序：逐集核对原片与截图 → 先精制首集地图、反派和演出 → 验证主角正侧背与动作 → PSP 实机优化 → 用经验证的内容管线逐季制作。上述事项均为待办，不是已完成工作。

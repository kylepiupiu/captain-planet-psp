# 美术制作说明

目标：将动画中的夸米、惠勒、琳卡、吉、马蒂、地球超人制作成 PSP 480×272 可识别的二维游戏角色。依据实际动画截图保留肤色、发型、服装、胸标与人物比例；当前生成结果仍需逐角色对照修订。

角色主图：透明背景六行六列，行顺序为上述六角色。每行包含正面站立/迈步、背面站立/迈步、右侧站立/迈步；左向通过镜像绘制。主图实际裁切坐标记在 tools/build_assets.py。运行角色单元 48×64，立绘单元 96×128。

道具主图：透明背景四行四列，包含树、棕榈、岩石、油井，工厂、毒桶、终端、船，以及象、海豚、小狗、熊猫、大猩猩、猫头鹰、海龟、犀牛。运行单元 64×80。

未完成：逐个姿态严格轮廓校正、攻击/受击/闪避/合体演出、反派专属造型、真实逐集环境。不把生成主图直接等同于原片设定稿。
